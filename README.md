# Pillow Thief

**Steal a cuddle. Keep the comfort.**

Pillow Thief is a cross-platform mobile application that connects adults seeking comfort, relaxation, and human connection with verified professional cuddle providers.

The platform is designed around consensual, non-sexual cuddling and companionship. It allows clients to discover providers, explore services, check availability, book sessions, arrange meeting locations, and communicate securely.

Providers can create professional profiles, manage their services and availability, accept bookings, and track their earnings.

## Features

- Cross-platform mobile application for iOS and Android.
- Client and provider registration.
- Provider profiles and verification workflows.
- Search and discovery of cuddle providers.
- Google Maps integration for location based discovery.
- Google Places Autocomplete for location search.
- Service area and house call management.
- Booking and scheduling system.
- Secure payment integration.
- Provider earnings and payout management.
- In-app messaging and notifications.
- Consent and personal boundary management.
- Reviews, reporting, and blocking.
- Administrative dashboard.
- Privacy focused location management.

## Technology stack

- React Native and Expo
- TypeScript
- Expo Router
- Supabase
- PostgreSQL
- Google Maps Platform
- Next.js for the administration dashboard

## Initial launch market

Gaborone, Botswana, with a technical architecture designed to support future expansion.

## Project status

Under development. Production functionality depends on implementation, testing, and configuration of the required external services.

## Privacy and safety

Pillow Thief is designed for adults aged 18 and above. All services are intended to be consensual and non-sexual. The platform prioritises user privacy, respect for personal boundaries, secure bookings, and responsible provider verification.
